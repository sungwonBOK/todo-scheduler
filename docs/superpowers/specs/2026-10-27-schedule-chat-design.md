# 일정 채팅 UI

승인된 흐름: 하단 채팅바 클릭 → 펼쳐지는 패널 → 메시지 입력 및 전송 → 닫기 및 재열기 시 대화 유지.

- 목표: 오늘/이번 주 화면에서 자연어 일정을 입력할 수 있는 프론트엔드 UI.
- 방식: 화면 전환 대신 하단 고정 패널. 전체 화면 방식보다 기존 일정을 보면서 입력하기 좋다.
- 범위: 메시지 말풍선, Enter 전송, Shift+Enter 줄바꿈, 한글 조합 중 전송 방지, 빈 메시지 방지, Escape 닫기, 입력 포커스, 작은 화면 대응.
- 이번 단계에서는 GPT 호출과 일정 저장을 하지 않는다. 화면에 준비 중임을 명시하고 사용자 메시지만 표시한다.
- 구조: dashboard layout에서 한 번 마운트. features/chat에 전용 상태와 패널 UI를 둔다. 기존 todo 상태는 변경하지 않는다.
- 보관: 현재 페이지 세션의 메모리 상태. 패널 닫기 및 오늘/이번 주 이동 시 유지하고 새로고침하면 초기화한다.
