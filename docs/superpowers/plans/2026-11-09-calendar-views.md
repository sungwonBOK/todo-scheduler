# 실제 날짜와 오늘·주간·월별 연결

사용자 승인 범위: 실제 날짜 적용, 오늘/주간 연결, 월별 추가. 추가 입력은 기존 우측 하단 챗봇만 사용한다. 추가 폼을 새로 만들지 않는다.

설계: 공유 TodoProvider를 유지하고 한국 날짜를 공통 기준으로 사용한다. 날짜만 있는 할 일은 시작 날짜에 표시하며 마감일까지 매일 복제하지 않는다. 시간 지정 일정은 시간표에 표시한다. 월별은 월요일 시작 달력과 선택 날짜 상세 목록으로 구성하고 모바일에서는 세로 배치한다. 완료 상태는 세 화면에서 공유한다. 데모 데이터는 실제 화면에 주입하지 않는다. 기존 Inbox 전면 제거/영구 저장/일정 이동 기능은 이번 작업에서 제외한다.

- [x] 날짜·주·월 경계와 날짜별 목록 테스트 작성 후 실행.
- [x] 공통 현재 날짜와 날짜 조회 규칙 구현. 한국 자정 및 복귀 시 갱신.
- [x] 오늘·주간에 날짜별 시간 미정 목록 연결, 기존 수동 추가 진입 제거.
- [x] 월별 달력·선택 날짜 상세 및 모바일/데스크톱 메뉴 연결.
- [x] 챗봇 날짜 전용 입력 지원 및 세 화면 완료/저장 통합 테스트.
- [x] 전체 테스트 및 프로덕션 빌드 실행, 변경 내역 검토.

검증 초점: 월말/연말/윤년, 한국 자정, 시간 미정과 미래 일정 분리, 여러 날짜에 걸친 시간 일정, 저장 실패 및 완료 상태 공유. 기존 테스트의 선행 실패는 별도로 기록한다.

검증 결과: localhost:3000/month 및 /week에서 실제 날짜, 월 이동, 메뉴 연결과 챗봇 유지 확인. 좁은 화면의 월별 달력도 확인. 날짜 전용·시간 지정 챗봇 저장과 완료 상태 공유는 API 경계 테스트로 확인했으며 실제 AI 유료 호출은 실행하지 않음. webpack 프로덕션 빌드 통과. 관련 6개 테스트 파일 49개 통과 후 자정 자동 갱신 회귀 테스트 추가 및 수정. 최종 전체 검사 101개 통과, 5개 실패, 1개 건너뜀.

남아 있는 기존 저장/수동 추가 테스트 실패(제품 코드는 이 기대에 맞춰 되돌리지 않음):
- tests/features/todos/TodoProvider.test.jsx: adds a pending todo and persists the full list; rehydrates a saved list instead of the initial seed list; persists a completion toggle. localStorage 기반 기대가 현재 API 저장과 불일치.
- tests/components/todos/TodoAddControl.test.jsx: shows required-field errors when confirmed empty; adds a valid todo and closes the dialog. 비동기 입력/저장 완료를 기다리지 않는 기존 테스트. 이 컴포넌트는 현재 화면의 진입점에서 제외하고 원본을 유지함.

독립 검토에서 발견한 자정 갱신 지연은 재현 테스트 실패를 확인한 뒤 다음 한국 자정에 맞춘 타이머로 수정했다. 시간표 밖/야간 일정은 해당 요일의 '그 외 시간' 영역에 표시한다.
